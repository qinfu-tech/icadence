# Product media

The icon and direct iPhone screenshots are existing iCadence assets from Qinfu Tech. Screenshots show the reminder timeline, routine editor and list, walking verification, break history, and system alarm. Screenshots are resized for readability and file size; they have no marketing frames or added backgrounds.

The English walkthrough preserves the full supplied screen recording, compressed without audio. The Simplified Chinese walkthrough is a short silent excerpt. The camera demo uses an avatar to cover the face. The Lock Screen Live Activity card is labeled as a development preview in both galleries.
