# Product artwork

The icon and screenshots are existing Qinfu Tech iCadence assets, reused for this official product showcase. Screenshots are available in English (`screenshots/en/`) and Simplified Chinese (`screenshots/zh-CN/`). The three selected views show the reminder timeline, walking verification, and routine setup.

Images are proportionally resized PNGs for GitHub; no interface content has been fabricated. Some screens include Pro features. Promotional artwork may differ from the current app's exact visual appearance.
